# Source Capture: S17 - A Practical Guide to Building AI Agents

Title: A Practical Guide to Building AI Agents

Author: OpenAI

Date: 2025

URL: https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/

## Why included

This practice guide gives pragmatic guidance about when to use Agents, how to design tools, when to use single vs multi-agent systems and how to add safeguards.

## Project use

- Supports the argument that multi-agent systems should not be introduced by default.
- Helps define human escalation and risk-based safeguards.
- Provides engineering framing for the reliable enterprise Agent topic.

## Cautions

Use as practical design guidance, not as a formal security or authorization specification.
