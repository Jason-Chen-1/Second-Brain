# Source Capture: S15 - NIST AI 600-1: Generative AI Profile

Title: Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile

Authors: Autio et al.

Date: 2024-07-26

DOI: https://doi.org/10.6028/NIST.AI.600-1

## Why included

This official NIST report provides a governance frame for generative AI risks. It helps connect technical Agent failures to organizational risk management.

## Project use

- Supports the governance layer of reliable enterprise Agent design.
- Provides vocabulary for govern, map, measure and manage.
- Helps justify why logs, metrics, human escalation and risk controls matter.

## Cautions

This is a governance framework, not an Agent implementation guide. Use it with technical evaluation sources such as S04, S05 and S06.
