# Raw Sources

`source_manifest.md` records all source metadata: source ID, title, URL or local filename, source type, shareability, quality, and intended project use.

To avoid duplicating copyrighted full text, this repository does not mirror public webpages or papers unnecessarily. Public papers may be manually downloaded as PDFs by the student. Webpages, repositories, and specifications use lightweight `.source.md` capture notes that point to the source and explain how the project uses it.
