# Source Capture: S10 - LLM Wiki

Title: LLM Wiki

Author: Andrej Karpathy

Date: 2026-04-04

URL: https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

## Why included

This is the original concept source for the LLM Wiki pattern used in this project. It defines the raw/wiki/schema structure and motivates the idea that an LLM can maintain a persistent Markdown knowledge base.

## Project use

- Baseline for the LLM Wiki architecture.
- Source for the distinction between raw sources, generated wiki pages, schema files, ingest, query and lint workflows.
- Source for the claim that a medium-sized source set can be maintained through an index-like wiki structure.

## Cautions

Treat this as an original design proposal, not as a controlled empirical evaluation. Use it to define the pattern, then test reliability through this project's stress tests.
