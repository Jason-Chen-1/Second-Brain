# Source Capture: S16 - MCP Security Cheat Sheet

Title: MCP Security Cheat Sheet

Author: OWASP Cheat Sheet Series

Date: continuously updated

URL: https://cheatsheetseries.owasp.org/cheatsheets/MCP_Security_Cheat_Sheet.html

## Why included

This security cheat sheet provides an attacker-oriented engineering checklist for MCP risks such as excessive permissions, secret exposure and tool poisoning.

## Project use

- Supplements S13 with OWASP-style practical security concerns.
- Supports guardrail, sandboxing and least-privilege desiderata.
- Useful for stress tests involving malicious tool descriptions or unsafe outputs.

## Cautions

Use as a security checklist, not as the sole normative MCP specification.
