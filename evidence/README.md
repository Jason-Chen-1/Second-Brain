# Evidence Folder

This folder stores audit materials that explain how the knowledge base changed over time.

Appropriate contents include:

- before/after diffs for important wiki or schema changes;
- screenshots of prompts, wiki pages, or observed outputs;
- copied terminal logs;
- exported page excerpts;
- saved maintenance or reproduction outputs.

Keep evidence minimal and relevant. Do not store private data, API keys, or non-shareable copyrighted material here.
